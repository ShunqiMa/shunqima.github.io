# Shunqi Ma - Academic Homepage

This is Shunqi Ma's academic homepage. It includes a biography, research news, selected publications, education, honors, and academic service.

## Preview locally

Open `index.html` in a web browser.

## Update the website

- Edit `index.html` to update the content.
- Edit `style.css` to adjust the visual design.
- Replace `assets/profile.jpg` to update the portrait.
- Add publication PDFs and images under `assets/publications/`.

## Publish with GitHub Pages

1. Create a public repository named `<your-github-username>.github.io`.
2. Upload the contents of this folder to the repository root.
3. In **Settings > Pages**, publish from the root of the `main` branch.
4. The website will be available at `https://<your-github-username>.github.io/`.
